# 数据集标签分析可视化工具

## 简介

`label_analyzer_gui.py` 是一个基于 `count_labels.py` 功能的图形用户界面工具，用于分析和统计数据集中的标签信息。该工具提供了直观的可视化界面，支持以下功能：

- 统计 `.annotate` 和 `.json` 格式的标注文件
- 按类别显示标签频率分布
- 支持多进程并行处理，提高分析速度
- 可视化图表展示统计结果
- 按类别整理数据集文件
- 自动生成统计报告
- 创建可视化样本

## 功能特性

### 1. 基本参数配置
- **数据集路径**: 选择包含标注文件的数据集根目录
- **输出目录**: 指定分析结果和整理后文件的输出位置
- **进程数**: 设置并行处理的进程数量（默认为CPU核心数）
- **采样数量**: 每个类别随机采样的文件数量

### 2. 过滤参数
- **忽略标签**: 指定需要忽略的标签（多个标签用逗号分隔）
- 默认忽略标签：`通用-不识别`

### 3. 输出选项
- **保存统计报告**: 自动生成详细的统计报告文本文件
- **创建可视化样本**: 生成带标注的可视化图片样本

### 4. 分析结果展示
- **统计结果**: 柱状图显示前15个最频繁的标签
- **详细信息**: 完整的统计报告文本
- **文件列表**: 按标签分类显示对应的文件路径

### 5. 数据集整理
- **按类别整理**: 将图片和标注文件按类别组织到不同子目录
- **自动过滤**: 自动跳过指定的忽略标签

## 使用方法

### 1. 启动工具
```bash
cd /home/industai/workspace/SubStation_AI_Poject
python statistic/label_analyzer_gui.py
```

### 2. 基本操作流程
1. **选择数据集路径**: 点击"浏览..."按钮选择包含标注文件的数据集目录
2. **设置输出目录**: 工具会自动根据数据集路径生成默认输出目录，也可以手动指定
3. **配置参数**: 
   - 在"基本参数"页面设置进程数和采样数量
   - 在"过滤参数"页面设置需要忽略的标签
   - 在"输出选项"页面选择是否保存报告和创建样本
4. **开始分析**: 点击"开始分析"按钮启动分析过程
5. **查看结果**: 
   - 在"统计结果"页面查看柱状图
   - 在"详细信息"页面查看完整报告
   - 在"文件列表"页面查看各标签对应的文件
6. **整理数据集**: 如需按类别整理数据集，点击"按类别整理数据集"按钮
7. **导出报告**: 点击"导出报告"按钮手动保存统计报告

### 3. 快捷操作
- **清除结果**: 点击"清除结果"按钮清除当前分析结果，重新开始
- **自动保存**: 如果启用了"保存统计报告"选项，分析完成后会自动在输出目录生成报告文件

## 支持的文件格式

### 1. .annotate 格式
```json
{
  "entities": [
    {
      "label": "变压器",
      "shapes": [...]
    }
  ]
}
```

### 2. .json 格式
```json
{
  "rois": [
    {
      "name": "断路器",
      "points": [...]
    }
  ]
}
```

## 输出文件结构

当分析完成后，输出目录将包含以下内容：

```
output_directory/
├── label_statistics_YYYYMMDD_HHMMSS.txt  # 自动保存的统计报告
├── visual_samples/                       # 可视化样本目录（如果启用）
│   ├── 类别1/
│   │   └── sample1.jpg
│   └── 类别2/
│       └── sample2.jpg
└── organized_dataset/                    # 整理后的数据集（如果执行整理）
    ├── 类别1/
    │   ├── image1.jpg
    │   └── image1.json
    └── 类别2/
        ├── image2.jpg
        └── image2.annotate
```

## 依赖要求

- matplotlib
- orjson
- Pillow (用于图像处理)

## 注意事项

1. **数据集结构**: 工具会递归扫描指定目录下的所有子目录，查找 `.annotate` 和 `.json` 文件
2. **内存使用**: 对于大型数据集，建议适当减少进程数以避免内存不足
3. **文件对应**: 工具会自动匹配标注文件对应的图片文件（支持 .jpg, .jpeg, .png, .bmp, .tiff 格式）
4. **中断恢复**: 目前不支持中断后继续，如需重新分析请清除结果后重新开始

## 常见问题

### Q: 启动时出现"ModuleNotFoundError"
**A**: 请确保安装了所有依赖包：
```bash
pip install matplotlib orjson pillow
```

### Q: 分析过程中程序无响应
**A**: 对于大型数据集，分析可能需要较长时间。请耐心等待，或减少进程数和采样数量。

### Q: 找不到对应的图片文件
**A**: 确保标注文件和图片文件在同一目录，且文件名（不含扩展名）相同。

### Q: 中文显示乱码
**A**: 工具使用系统默认字体，如需更好的中文支持，请确保系统已安装中文字体。
